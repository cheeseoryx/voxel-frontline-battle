## 实现
- 大征服 6、小型战斗 3 切换所选战斗刀；核心攻防与枪械模式仍不开放持刀。按住左键连续挥砍，松开后完成当前刀并停止连挥；切槽、投掷、建造、乘车、死亡、失焦和离局中断旧动作。
- 使用原版 90 点正面伤害、999 点背刺伤害、2 米范围、60° 半角（总角度 120°）；背刺按目标朝向与双方水平位置计算，背后 120° 范围成立。攻击距离从身体到目标胸口计算，视锥和遮挡从眼睛到胸口计算，近距离优先，0.08 米内按视线接近程度破同距离。
- 0.05 秒起手、0.15 秒有效窗口、0.25 秒恢复，0.45 秒连挥间隔；有效窗口内未命中可继续寻找目标，每刀最多命中一人。低帧率跨越起手与有效窗口时不会丢失整刀的判定。刀不打穿墙/烟、不伤载具/核心/地形，不消耗枪弹；交由既有 arena 处理阵亡和战绩。
- 持刀走路 1.12 倍、冲刺 1.18 倍装备系数；落地时对 2.6 米内、稍超出攻击距离的目标突进，速度 10 米/秒，最多 0.6 米，冷却 0.3 秒。突进使用同一个 Rapier 角色控制器，不能穿墙；跳起、目标失效或离开有效窗口后停止。按照身体/胸口实际高度换算水平突进终点，避免原线性距离减法在平地仍差约 2 毫米导致突进空刀；攻击半径和最大位移不变。
- 挥砍动作按原版两套肩轴与姿态曲线执行，右侧持刀手和刀一起运动，护卫手保留原位置。导入新增 32 个拆分网格，原有 188 个模型的编码哈希逐个保持一致；总数 220。角色、背景、模型配色和原网格未重画。
- 原版六种近战声音（两套模式各挥刀/命中/背刺）及其滤波与包络在构建期执行并烹制为 WAV，由造化 AudioSource 播放。近战增加恢复式镜头冲击、原 UI 准星命中/击杀标识和背刺提示；命中处以造化 Standard 材质显示短暂的红橙/金色冲击网格。通用枪械反馈仍属于 EQ-07 / EQ-08。
- 小型五种模式最终结束后自动检视当前武器，支持枪械与当时持有的刀，阵亡也可显示；建造/投掷状态退回武器显示。采用原版抬起、转动、支撑臂、镜头和 FOV 曲线，完整播放 2.4 秒后才显示结算，鼠标不能跳过，期间不能射击、换弹、切换或移动。
- 检视期间暂停战斗 owner 与 Rapier 步进，结算倒计时从展示结束后继续；中途离局清理，重进不继承展示状态。爆破的中间回合不触发，最终回合才触发。原版爆炸结算的 1.5 秒最低等待被 2.4 秒检视覆盖，不额外增加等待。
- 大征服仍直接显示本身的结算，不新增检视按键。小型“自由触发局内检视”并不存在于原版，所以不增加该操作。
