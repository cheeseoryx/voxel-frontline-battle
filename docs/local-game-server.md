# 本地游戏服务

双击项目根目录的“启动游戏.cmd”，即可在后台启动服务并用默认浏览器打开首页。已正常运行时不会重复启动。也可直接执行 scripts/start-game-server.ps1。

固定地址：http://127.0.0.1:8765/ 。服务显式绑定本机地址，根目录从启动脚本位置确定，不依赖打开终端时所在目录。

后台进程使用隐藏窗口，标准输出和请求/错误日志写入 tmp/game-server/；state.json记录进程号、启动时间与日志路径。启动完成前会请求首页并核对返回内容是否等于当前项目的index.html。

如果端口被其他进程占用，启动器会报告进程号并停止，不会自动结束未知服务。退出浏览器不会停止这个后台服务；电脑重启后重新运行启动器。它是本地静态游戏服务，不是公网专用对战服务器。
