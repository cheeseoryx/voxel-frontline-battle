# 《逃离鸭科夫》参考拆解与本项目取舍
核实日期：2026-09-11。资料基线为官方商店介绍和下面逐项链接的社区条目；没有对完整当前发行包逐物品实测。

## 1. 原作核心循环

玩家带装备离开安全基地，在危险区域搜索、交战、完成任务，撤离后处理物资，再将物资投入装备和基地。官方明确介绍了 PVE、探索、基地建设、装备改装与任务。本项目只继承其中的单次冒险结构。[官方介绍](https://store.steampowered.com/app/3167020/Escape_from_Duckov/?l=schinese)

可提炼的设计作用：
- 出发目标让地图搜索有方向。
- 地图上不同危险与收益使玩家决定是否深入。
- 消耗和背包限制让“多带一件”有成本。
- 撤离把未兑现的收获变为确定结果。
- 原作跨局发展提供再次出发的动机；本项目改由不同地图、目标组合、装备发现、路线解法和本局评级提供重玩动机。

后一组是设计分析，不是官方给出的机制解释。

## 2. 原作系统与本项目映射

### 战斗和武器
原作支持多类武器和改装，配件涉及瞄具、弹匣等不同用途。本项目保留武器类型和射击手感，彻底移除配件槽、兼容配件表、拆装界面和随机词条。[官方介绍](https://store.steampowered.com/app/3167020/Escape_from_Duckov/?l=schinese)、[社区配件条目](https://escape-from-duckov.fandom.com/wiki/Attachments)

### 弹药
社区条目将弹药按武器类别和不同弹种区分。本项目压缩为轻型、步枪、重型、霰弹四种通用弹药，不设置弹药品质与穿甲弹经济。武器类型决定基础穿透，品质只应用固定增益。[社区弹药条目](https://escape-from-duckov.fandom.com/wiki/Ammunition)

### 装备和携行
原作存在可穿戴装备、背包等物品。采用“携行能力与生存能力影响探索选择”这一思路；本项目只保留头盔、护甲、背包三个部位，每部位四种固定品质。[社区装备条目](https://escape-from-duckov.fandom.com/wiki/Equipment)

### 基地与仓库
原作基地提供仓库、补给、休息和多个设施。当前方案全部取消基地经营与跨局储存；出战整备就是统一大厅中的一个页面。[社区基地条目](https://escape-from-duckov.fandom.com/wiki/Bunker)

### 制造、维修、蓝图
原作工作台支持制造、分解、维修和蓝图相关操作。本项目取消这些流程，找到的装备直接可用；未使用的装备只能携带、替换或丢弃。[社区工作台条目](https://escape-from-duckov.fandom.com/wiki/Workbench)

### 技能与构筑
原作技能强化具有经验和资源要求；图腾提供被动效果。本项目不保留经验、技能、图腾、天赋或额外构筑槽。构筑全部来自当局武器类型、品质、消耗品组合与路线。[社区技能条目](https://escape-from-duckov.fandom.com/wiki/Skills)、[社区图腾条目](https://escape-from-duckov.fandom.com/wiki/Totems)

### 任务与探索
原作任务引导探索并推动进程。本项目采用独立可重复生成的局内合同，每局重新分配，没有跨局任务链。钓鱼等休闲活动虽然存在相关原作任务，但不纳入本项目首个正式版。[官方介绍](https://store.steampowered.com/app/3167020/Escape_from_Duckov/?l=schinese)、[社区钓鱼任务条目](https://escape-from-duckov.fandom.com/wiki/Fishing_Hobbyist)

### 钥匙、捷径与环境
原作有钥匙登记和环境风暴等系统。本项目不继承永久钥匙登记；通行卡只本局有效，并始终为关键路线提供破坏或交互替代路径。环境危机作为单局可读事件，不制造长期抗性成长。[社区钥匙设施条目](https://escape-from-duckov.fandom.com/wiki/Master_Key_Recorded)、[社区风暴条目](https://escape-from-duckov.fandom.com/wiki/Storm)

### 首领
原作首领有专属装备和行为。本项目每张地图配置一名可选首领，奖励主要是当局品质提升和高价值货物。主合同不能依赖低概率首领刷新。[社区首领条目](https://escape-from-duckov.fandom.com/wiki/Boss)

## 3. 原作物品体系的有效归类

下面只用于理解功能，不是复制原作完整物品数据库：
- 战斗工具：枪械、近战、弹药、配件。
- 生存装备：身体、头部、脸部、背包及容器。
- 即时补给：医疗、食物、饮料、特殊消耗品。
- 场景通行：钥匙、卡片和任务道具。
- 建设与制作：工具、电子零件、建材和蓝图。
- 成长构筑：技能资源、图腾等。
- 收藏与价值：贵重物、收藏品和可出售杂物。

社区总物品页包含空 ID、重复项、开发测试物和不可正常获取的物品，因此不能把该页行数当作正式版可获得物品数。本方案不宣称已经列全原作当前版本的全部物品；附带的 96 项是**本项目完整计划内容池**。[社区物品说明](https://escape-from-duckov.fandom.com/wiki/Items)

## 4. 转换后的范围约束

保留搜索、战斗、撤离、敌人装备掉落、有限携行、多目标探索。
简化武器、弹药、防护和负面状态。
删除所有长期资源积累，以及依赖这些资源的设施、交易、制造和成长。
新增体素破坏路线、单局合同、明确的撤离评级与完整的当前对局恢复。

不得重新引入“用战报积分解锁初始装备”“用金色装备碎片兑换新枪”“根据账号等级增加背包”等换名的长期养成。设置中的画面、音量、键位、难度偏好可以保存，但不能改变下一局能力上限。
