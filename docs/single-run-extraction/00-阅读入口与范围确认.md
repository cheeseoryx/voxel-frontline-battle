# 单局搜打撤策划包
版本1.0 · 2026-09-11 · 当前项目单人模式 · 状态：设计基线，尚未实施

## 最重要的决策

本版严格依据最新要求：**一局内完成搜索、战斗、装备提升、任务和撤离；结算后所有局内财产清零；没有任何长期养成；没有武器配件。**

建议模式名“孤线撤离”。继续使用当前体素风格、第一人称射击、角色与背景素材。品质只采用固定系数，既不拼配件，也不滚随机词条。

完整一局：
首页 → 进入大厅 → 单人搜打撤 → 选择地图/普通装备方案 → 搜索与交战 → 取得合同物 → 带出贵重品 → 单局评分 → 再来一局/返回大厅。

保存并退出只恢复同一局；不存在下局拿上局武器、存仓库、出售、领取货币、升技能或解锁地图。所有地图和起始方案从第一局开放。

## 正式版内容与实施顺序

正式版目标为3张地图、12种基础枪械×4品质、3类装备×4品质、36条无品质道具，共96条定义。48条枪械定义只对应12种基础武器表现，品质不要求复制模型。

搭配9个主合同模板、12个可选委托、6种事件、8种普通AI与3名首领。每局选一个主合同和三个委托，不是把全部任务塞入一局。

先完成1地图、3枪、基础掉落、1目标、2撤离点、成功/死亡结算及当前局恢复。再验证完整地图切片，最后扩充正式内容。有限结构坍塌需通过引擎基线，不能假定当前已达到Teardown级别的破坏表现。

## 估算与未决实施验证

按5名核心成员、现有战斗与资产可复用的假设，阶段预算含缓冲约25–34周。50个工作包粗估合计194–320人日，日历时间另外包含跨角色依赖、试玩、返工和发布验证；二者不可直接等同。未确认团队与引擎基线前，不能将此作为固定工期承诺。

以下不是待补的玩法规则，而是实施阶段必须测量的事实：旧碰撞与寻路可复用程度、破坏后导航成本、基准PC帧时间、三种初装实际通关表现、地图路程与新玩家理解成本。

数值都是本项目首次调试值。资料引用只支持原作系统拆解，不为本项目数值背书。本轮未改游戏源码、现有UI、角色或背景。
