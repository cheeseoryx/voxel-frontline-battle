# 完整物品目录（96条定义）

版本1.0 · 全部为当前项目的原创单局配置初值，并非《逃离鸭科夫》的原物品数据库。武器与防具只存在四个固定品质；其余物品无品质、无词条、无配件。

本目录由data/content.json生成。容量按一叠或一个独立物品计算。枪械伤害为每发射弹/每弹丸；霰弹必须乘实际命中弹丸数，不能再按整枪伤害重复相乘。射速单位发/分钟，换弹单位秒。无品质变化的枪械字段从baseId对应基础武器读取。

## 3. 来源类型与放置要求

weapon_case武器箱；equipment_case装备箱；supply_case补给箱；medical_case药箱；tool_case工具箱；valuable_case贵重箱；elite_cache精英藏物；enemy实际敌人库存；fixed_supply生成时固定补给；contract_anchor主合同锚点。

source表达允许来源，不是保证每个箱生成全部类型。普通箱按类别权重抽取，最多一件枪械/装备；药箱等专属容器只使用对应类别。相同品质权重适用于枪械、护甲、头盔和背包，合同物不走随机掉落。

目标物每局只预放当前主合同需要的一个。其他合同物不作为随机垃圾占格。工具桥板和信号电池有明确使用地点，通行卡只开可选奖励房。副委托不会要求稀有随机物：需要的物件/交互点在生成时保证。
