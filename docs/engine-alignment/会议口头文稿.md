# 项目对齐会议口头文稿 · Teardown 目标与最新进度说明

【开场与目标修正】
今天主要对齐三件事：当前已经完成的内容、最终参加比赛的形态，以及需要平台支持的能力。先明确一个核心目标：我们的场景表现和画面品质要向 Teardown 对齐，做成极高自由度、大部分场景都能破坏的体素世界。这个目标会贯穿单机和 PVP。此前材料对破坏范围的描述偏小，这次以这里的目标为准。项目后续会作为新引擎官方演示项目公布，我们希望把这项能力作为项目的核心展示内容。

【现状展示】
我们先按项目代码、文档与本轮验证记录，通过进度网页看一下目前的基础，附件录像只作辅助参考。模式大厅、装备整备和部署流程已有整合，射击、载具、场景破坏及编辑器也有现有实现。联机方面，同房加入和访客整备本轮通过；部署后的 AI 席位替换检查未通过，需要定位后复核。这些是我们继续推进的基础；当前完成度会按实际录像和测试环境说明，距离 Teardown 目标的差距需要这次一起评估。

【单机与 PVP 形态】
单机玩法可以用鸭科夫式搜打撤来理解，结合我们的武器、道具、载具和丧尸战斗。玩家能搜索、开车、打枪和撤离，也能自己破墙、拆除结构或用车辆撞开路线，在被改变的场景里继续行动。现有的一局内体验方向先保持，重点把自由破坏真正接进玩法。
PVP 则保留战地式大战场和 COD 式小型交战的核心方向。我们希望破坏能改变双方的掩体、射界和推进方式，并且双方看到、碰到的是同一个变化后的世界。比赛版本重点做哪些模式、真人规模多大，可以结合验证结果确认。

【物理与引擎支持】
引擎支持的重点，需要从基础碰撞进一步扩展到动态体素世界：能在不同位置持续破坏；结构断开后有分离、下落和碰撞；残骸留下来以后还能交互；人物、车辆和 AI 都能适应新的空间。联机还需要同步这些关键变化，包括后来加入的玩家恢复当前世界。希望平台明确已有能力、差距、可接入方案和验证节点。

【画面与特效】
画面参考已经明确为 Teardown。我们希望对齐它的体素细节、材质、光照层次，以及破坏过程中和破坏之后的整体质感。特效仍是一个卡点，尤其是爆炸、烟尘、碎片、坍塌和撞击。我们希望这些表现和真实结构、碰撞、受光一起成立。配套目标资料保留官方商店参考图，接下来可以共同选镜头建立实时样板。

【工具与第一步验证】
工具方面，我们已有场景编辑基础，希望重点补齐可破坏体素资产的制作流程，包括模型体素化、材质、结构连接和碰撞配置。AI 已能稳定完成的部分我们自己处理，平台支持集中在实际接入和制作卡点。建议先共同做一个小型综合场景，把大部分可破坏、坍塌交互、目标画面和联机一致性跑通，再扩展内容。

【收尾】
这次希望确认的是：平台用什么路径支持这个目标，第一份可运行样板由谁在什么时间交付，以及用什么设备和场景验证。需要调整范围的地方，请把原因和影响列清楚，让我们明确决策。这样比赛版本和官方演示项目就能按同一个目标推进。
